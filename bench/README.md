# Стенд сравнения ИИ-провайдеров

Автономная утилита: прогоняет одинаковые сообщения городских служб через разные
модели и сравнивает их по тому, что важно для «Радара» — правильность категорий,
точность извлечения улиц и домов, отсутствие ложных тревог и, отдельно,
способность вообще разбирать военную тематику.

Стенд не входит в бота и не попадает в Docker-образ. Запускается вручную,
результат — таблица и два файла отчёта.

## Зачем

1. **Проверить доступность.** Groq, Cerebras, OpenAI и часть других блокируют
   российские IP. Единственный способ узнать — постучаться с самого сервера.
2. **Проверить фильтрацию военных тем.** Половина функциональности «Радара» —
   оповещения о БПЛА и ракетной опасности. Китайские и часть западных моделей
   могут отказываться разбирать такие сообщения, возвращая пустой ответ или
   отказ. Три кейса в наборе помечены `sensitive` и проверяют именно это.
3. **Сравнить качество на своих данных**, а не по чужим бенчмаркам: русские
   адреса с сокращениями, диапазоны домов, «улица имени Чапаева В.И.».

## Запуск

```bash
cd bench
cp .env.example .env      # вписать ключи, которые есть
./run.sh --probe          # кто вообще отвечает с этого сервера
./run.sh --list-models    # какие модели реально живы у каждого ключа
./run.sh                  # полный прогон
```

`run.sh` поднимает одноразовый контейнер `python:3.11-slim` — на хост ничего
ставить не нужно. Если Python и `aiohttp` уже есть, можно напрямую:
`python3 bench.py --probe`.

Проверить логику подсчёта без сети и без зависимостей:

```bash
python3 bench.py --selftest
```

### Полезные флаги

| Флаг | Что делает |
|---|---|
| `--providers groq,deepseek,zai` | только указанные провайдеры |
| `--first-model-only` | по одной модели на провайдера (быстрее и дешевле) |
| `--quick` | сокращённый набор кейсов |
| `--verbose` | показывать оценку по каждому кейсу |
| `--live saratovzhkh` | добавить свежие посты канала (эталона нет, смотреть глазами) |
| `--probe` | только проверка доступности |
| `--list-models` | реальные каталоги моделей |

## Порядок, который я советую

1. `./run.sh --probe` — отсекает всех, кто недоступен из вашей сети. Дальше
   работать только с выжившими.
2. `./run.sh --list-models` — покажет, живы ли модели из реестра. Каталоги
   меняются молча, именно так пропал `gemini-2.5-flash`.
3. `./run.sh --first-model-only --verbose` — первый содержательный прогон.
4. Смотреть в первую очередь на колонку **БПЛА**. Модель с качеством 85%,
   которая срезает военные темы, для «Радара» хуже модели с 70%, которая их
   разбирает.

## Что считается

| Метрика | Как считается |
|---|---|
| Качество | 50% категории (F1) + 15% масштаб + 35% адреса, либо всё на категории, если адресов в эталоне нет |
| JSON | доля ответов, из которых удалось достать валидный объект |
| Военные темы | сколько из трёх `sensitive`-кейсов модель отбросила или отказалась разбирать |
| Ложные тревоги | шумовые кейсы (розыгрыш, спорт, благоустройство), признанные значимыми |
| Пропуски | значимые события, признанные шумом |
| Задержка | медиана по всем запросам |

Шумовые кейсы оцениваются бинарно: либо модель промолчала и получила 1.0,
либо подняла ложную тревогу и получила 0.0. Для системы оповещения ложная
тревога дороже неточного адреса.

## Провайдеры в реестре

**США:** Google Gemini, Groq, Cerebras, OpenAI, Anthropic, GitHub Models,
NVIDIA NIM, Together, SambaNova, OpenRouter (агрегатор)
**Европа:** Mistral (Франция) · **Канада:** Cohere
**Азия:** DeepSeek, Z.ai / Zhipu GLM, Moonshot Kimi, Alibaba Qwen, MiniMax

Добавить своего — одна запись в `providers.py`. Если API OpenAI-совместимый,
больше ничего писать не нужно.

## Оговорки

- Цены в реестре ориентировочные, на август 2026, для оценки порядка величин.
- Бесплатные тарифы почти всегда означают, что запросы идут на обучение модели.
  В стенде отправляются только синтетические сообщения — реальных адресов
  пользователей в них нет.
- Один прогон — это один замер. Модели недетерминированы, для спорных случаев
  прогоняйте дважды.
- `report.json` содержит полные ответы моделей: удобно смотреть, что именно
  напутала модель с адресами.
