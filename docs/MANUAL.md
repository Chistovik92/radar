# Радар — инструкция по использованию

Бот, веб-панель и командная строка — три способа управлять одной системой.
Документ собран по коду версии 5.9.10.1.
Английский вариант — [MANUAL.en.md](MANUAL.en.md). Подробности установки, настроек и
каждой возможности — в [README.md](../README.md); здесь — порядок работы и справочник.

> Система не заменяет официальные каналы оповещения.

Что **не** проверялось на живой системе, помечено ⚠️. Если пункт расходится с тем,
что вы видите на сервере, верьте серверу и сообщите автору.

---

## 1. Три способа управления

| Способ | Где работает | Когда удобен |
|---|---|---|
| Бот в Telegram (также MAX, ВК, Discord — слабее) | в мессенджере | повседневное: меню, пользователи, ответы людям |
| Веб-панель | в браузере, по домену, вход через Telegram | широкие формы: ключи, партнёры, VPN, настройки, журналы |
| Командная строка | терминал сервера | ssh, cron, скрипты, когда панели или браузера нет |

Права одинаковы везде: панель и CLI не дают больше, чем роль в боте.
**Терминала сервера в веб-панели нет и не будет** — это решение проекта.

### Роли

| Действие | Пользователь | Модератор | Администратор | Суперадмин |
|---|:--:|:--:|:--:|:--:|
| Свои локации и настройки | ✅ | ✅ | ✅ | ✅ |
| ИИ-ассистент в диалоге | — | ✅ | ✅ | ✅ |
| Модерация источников | — | ✅ | ✅ | ✅ |
| Правка чужих локаций и оповещений | — | ✅ | ✅ | ✅ |
| Удаление пользователей, назначение модераторов | — | — | ✅ | ✅ |
| Назначение администраторов | — | — | — | ✅ |

Действовать можно только на тех, кто **уровнем ниже**. Суперадмина изменить нельзя.
Доступ в бота — по инвайт-ссылке из меню «Пользователи».

## 2. Бот

### Начало работы пользователя

1. `/start` или `/menu` — главное меню.
2. Добавьте адрес (локацию): улица, дом, город. **Без подтверждённой географии
   тревога не отправляется** — это правило проекта, а не недочёт.
3. Выберите, о чём оповещать; при желании задайте тихие часы и часовой пояс.
4. Оповещения об угрозах бесплатны всегда. Платными бывают только новостные подборки.
5. Событие в прошлом приходит как сводка, а не как тревога.

### Команды

Общие: `/start`, `/menu` — меню · `/id` — ваш ID и роль · `/cancel` — сбросить ввод ·
`/help` — справка · `/language` — язык интерфейса · `/link` — общий аккаунт
с другой сетью · `/panel` — ссылка на веб-панель · `/partner` — партнёрские проекты ·
`/digest` — новостные подборки · `/sub`, `/subscription` — подписка ·
`/check <ссылка>` — проверка ссылки на признаки мошенничества (если включена).

Модератор и выше: `/ai`, `/aireset` — ИИ-ассистент · `/quota` — расход квоты.

Администратор и выше: `/stats`, `/models` — статистика и модели.

Суперадмин: `/features` — возможности · `/logs`, `/logtail`, `/logclear` — журналы ·
`/keys` — ключи · `/backup` — копии · `/network` · `/perf` · `/metrics` ·
`/provider` — смена провайдера ИИ · `/setmodel` · `/ai_admin` · `/bench` ·
`/cookies` · `/media` · `/music` · `/short`, `/shorts`, `/shortclear` ·
`/digestprice` · `/history` · `/sos`.

В группах (модерация): `/chats`, `/modon`, `/modstatus`, `/warn`. Новичок
в группе ограничивается до нажатия кнопки «Я не бот».

⚠️ Какая именно роль нужна для каждой из последних команд, в этом документе
не проверялось; ориентир — таблица ролей выше и README, раздел «Команды».
Бот сам откажет, если прав не хватает.

### Возможности (флаги)

Всё заметное включается и выключается суперадмином на живой системе. Новое
приезжает **выключенным**. Ядро (например, оповещения) выключить нельзя.
Включить: бот `/features`, панель «Возможности», CLI `features on <ключ>`.

## 3. Веб-панель

Адрес — `https://ваш-домен` (порт `WEB_PORT`, по умолчанию 8080, за обратным
прокси). Вход — виджет Telegram, поэтому:

1. В @BotFather: `/setdomain` → выберите бота → пришлите `https://ваш-домен`
   точно, без пути в конце.
2. По IP-адресу вход не работает вообще — это ограничение Telegram.

Если домена нет, у панели есть вход по коду (`/login/code`) ⚠️ не проверялось.
Панель включается флагом `web_panel`.

### Разделы

| Раздел | Что внутри |
|---|---|
| Обзор | сводка состояния |
| Пользователи | список; пояс и время погоды у пользователя (модератор) |
| Источники | добавить/удалить Telegram-каналы, RSS, сообщества ВК (модератор+) |
| Возможности | переключатели (суперадмин) |
| Ключи | ключи ИИ и токены; вводятся, но показываются маской |
| Агенты | ИИ-агенты и модели |
| Файлы | раздача файлов: кому выдана ссылка, срок, досрочное отключение |
| Ссылки | короткие ссылки |
| Чаты | группы под модерацией: включить, пригласительная ссылка, объявление, отправка |
| Копии | создать и скачать резервную копию |
| Обслуживание, Медиа | диск, кэш, база, загрузка видео |
| Облако | музыка в облаке (rclone) |
| VPN | панели, доступы, отзыв доступа приложений |
| Подписки | выдача и отмена подписок |
| RustDesk | сервер удалённого доступа |
| Партнёры | партнёрские проекты и промокоды, экспорт |
| Настройки | все настройки `.env` по разделам, перезапуск |
| Журнал, События | аудит и поток событий |
| Обновление | обновление до последнего выпуска (флаг `panel_update`) |
| Удаление | снос установки (флаг `panel_wipe`) |

Безопасность: формы защищены токеном сессии; в журнал панели пишется имя
изменённого ключа, но не значение. Темы — кнопка в шапке: светлая → тёмная →
«Матрица» → «Реактор».

## 4. Командная строка

### Как запускать

С хоста (рекомендуется):

```bash
bash ~/radar_bot/tools/radarctl.sh --help
bash ~/radar_bot/tools/radarctl.sh <команда> [аргументы] [--json]
```

Внутри контейнера: `python -m radar.cli <команда>`. Нестандартный каталог —
`RADAR_HOME=/путь`, нестандартное имя контейнера — `RADAR_CONTAINER`.

Команды данных выполняются **внутри контейнера** (там база и `.env`). Команды
установки — **на хосте**: `update`, `restore`, `wipe`.

### Справочник (по `build_parser`)

| Команда | Действия | Примечания |
|---|---|---|
| `sources` | `list`, `add <вид> <значение>`, `remove <вид> <значение>`, `prune` | вид: `telegram`(`tg`) / `rss` / `vk`; у `prune`: `--days N` (30), `--dead`, `--yes`, `--force`, `--pause СЕК` (0.8) |
| `users` | `list [--role]`, `show`, `role`, `delete`, `time`, `stale [--prune]` | суперадмина изменить нельзя; `stale` — заблокировавшие бота |
| `features` | `list`, `on <ключ>`, `off <ключ>` | действует сразу, если бот запущен |
| `keys` | `list`, `get`, `set`, `unset`, `pending` | значения проверяются, как в панели; секреты — маской |
| `backup` | `list`, `create` | |
| `db` | `size`, `vacuum`, `copy` | у `copy`: `--from sqlite\|postgres`, `--to …`, `--replace`, `--yes` |
| `links` | `list`, `add <адрес>`, `remove <код>`, `clear` | `--yes` для разрушающих |
| `chats` | `list`, `on`, `off`, `forget`, `clean`, `invite`, `announce`, `warns` | `clean` и `announce --yes` — только из запущенного бота |
| `files` | `list`, `remove <токен>` | `--yes` |
| `rustdesk` | `info`, `connections`, `start`, `stop`, `restart` | `--yes` |
| `vpn` | `check`, `selftest`; `panels`, `panel-save\|remove\|check`; `access`, `issue`, `extend`, `on`, `off`, `revoke`, `deny`; `orders`, `order-confirm\|retry\|cancel`; `app-revoke` | см. README |
| `subs` | `list`, `codes`, `grant`, `revoke`, `code-add`, `code-drop` | подписка бота |
| `partners` | `list`, `show`, `save`, `remove`, `export` | `save --set поле=значение` |
| `ai` | `status`, `models`, `set-model`, `provider`, `health`, `ask`, `reset`, `bench`, `agents`, `agent-save\|remove\|model` | часть — только у запущенного бота |
| `metrics`, `perf`, `net` | — | `perf --reset` |
| `check`, `cookies`, `history`, `events` | `check URL [--no-net]`, `cookies status\|set ФАЙЛ`, `history UID`, `events` | |
| `music`, `cloud` | `music usage\|list`; `cloud list\|check\|add\|forget` | |
| `stats`, `logs`, `audit` | `stats`; `logs list\|tail\|clear`; `audit tail\|clear` | |
| `restart` | — | `--yes`; на хосте — `radarctl.sh restart` |
| `doctor`, `version` | `doctor --quick` | |
| Хост | `update`, `restore ФАЙЛ`, `wipe --yes`, `restart` | не из контейнера |

Язык вывода — `--lang ru|en` или `RADAR_LANG`; иначе язык системы (`C.UTF-8` — русский).

У команд есть `--json`. Разрушающие действия без `--yes` ничего не делают и
возвращают код **2**; ошибка — код **1**; успех — **0**. Так cron отличает
«не подтвердили» от «сломалось».

### Как команда доходит до бота (с 5.9.3)

Команды данных не выполняются отдельным процессом: консоль передаёт строку
запуска работающему боту через сокет `data/admin.sock` (права 600), и бот
исполняет её в своей памяти. Поэтому `features on digest` действует сразу,
без перезапуска, а правка источников не затирается сохранением бота.

- Бот не запущен — сокета нет; команда пойдёт прямо в базу, и консоль
  скажет об этом в stderr.
- `--local` или `RADAR_CLI_LOCAL=1` — всегда напрямую.
- `doctor`, `version`, `db copy` бота не касаются.
- Если связь оборвалась уже после отправки, команда не повторяется сама:
  проверьте результат командой `list`.

⚠️ В настоящем контейнере через `docker exec` не проверялось.

### Примеры для cron

```bash
# копия каждую ночь; код 1 — ошибка, cron пришлёт письмо
15 3 * * *  bash /home/USER/radar_bot/tools/radarctl.sh backup create

# раз в неделю показать молчащие источники, ничего не удаляя
0 9 * * 1   bash /home/USER/radar_bot/tools/radarctl.sh sources prune --days 30 --json

# быстрая диагностика
*/30 * * * * bash /home/USER/radar_bot/tools/radarctl.sh doctor --quick
```

### Чего в CLI нет намеренно

Паритет с ботом и панелью закрыт (5.9.10). Вне консоли остаются вход в панель,
скачивание файлов, меню подборок, загрузка видео по ссылке человека и SOS: это
действия самого человека, а SOS за другого посылать нельзя. Полный список с причинами —
`tools/lint_cli_parity.py`.

## 5. Группы и платформы

### Telegram: группы

Бот добавляется администратором (права «Удаление сообщений» и «Блокировка
участников»), затем в группе `/modon`. Модерация (`moderation`) удаляет спам и
чужие ссылки, ведёт лестницу «предупреждение → мут → бан», встречает новичков
кнопкой «Я не бот». Отдельными выключенными флагами (с 5.9.4):

- `captcha_kick` — не нажавший за 5 минут исключается (бан и сразу разбан);
- `deleted_cleanup` — `/cleandeleted` у администратора группы (или
  `radarctl.sh chats clean -100…`): проверка **известных боту** участников и
  исключение удалённых аккаунтов. Bot API не отдаёт список участников, поэтому
  охват в отчёте — «известно X / Y»;
- `cas_check` — сверка вступающих с внешней базой спамеров CAS (уходит только
  числовой идентификатор).

Заблокировавшим бота тревоги больше не отправляются; список —
`radarctl.sh users stale`.

### Discord

Флаг `platform_discord` и токен бота — сводки и статус; тревоги по адресам — в личные
сообщения связанного аккаунта (`/link`). Поверх (всё выключено по умолчанию):

- **Проверка участников** (`discord_verify`, с 5.9.5): кнопка «Я человек» → вопрос в
  окне → роль «проверен»; связанный через `/link` аккаунт проходит без вопроса;
  при вступлении — возраст аккаунта и имена с рекламой; тайм-аут. Настройка на
  стороне сервера Discord (роль, права бота, закрытые каналы, `/verifysetup`) — в
  README. Надёжно доказать человека нельзя — это поднимает цену автоматического входа.
- **Музыка по ссылке** (`discord_music`, с 5.9.7): `/play` (ссылка или слова),
  `/skip`, `/pause`, `/resume`, `/stop`, `/queue`. Нужен `requirements-voice.txt`
  (`discord.py[voice]`, шифрование DAVE), ffmpeg и права «Подключаться» и «Говорить».
  Spotify, Apple Music, Deezer не открываются; проигрывание с YouTube нарушает его
  условия.

### Языки

Русский, английский, украинский, персидский, китайский упрощённый — `/language`
в Telegram, `/lang ru|en|uk|fa|zh` в ВК, MAX и Discord. Переводы сделаны без
носителей языка: правки присылайте автору.

## 6. Установка, обновление, откат

Установка — один скрипт `install.sh` (Debian/Ubuntu, Docker; бот работает
в контейнере `radar_container`). Полная процедура и таблица переходов
между версиями — в README. Правила, которые нельзя пропускать:

- **Перед любым обновлением** — копия: `radarctl.sh backup create`.
- Обновление: `radarctl.sh update` или раздел «Обновление» в панели.
  Переход со старых версий идёт ступенями; ступень 4.6.0 пропускать нельзя.
- Восстановление: `radarctl.sh restore ФАЙЛ`.
- Удаление: `radarctl.sh wipe --yes` или раздел «Удаление» в панели
  (нужен флаг `panel_wipe`).
- **Не запускайте бота на Windows**: образ собирается под ARM, установщик —
  под Debian/Ubuntu.

## 7. Если что-то не так

| Симптом | Что проверить |
|---|---|
| `bad interpreter` у `install.sh` | файл стал CRLF; нужно LF |
| В панели «Bot domain invalid» | не сделан `/setdomain` у BotFather или адрес не совпадает |
| Флаг включён командой, но не работает (до 5.9.3) | обновиться до 5.9.3 или перезапустить бота |
| Бот не поднимается после обновления | `radarctl.sh doctor`, затем журналы `docker logs radar_container` |
| Тревога не пришла | есть ли подтверждённый адрес; включён ли флаг; не тихие ли часы; не режим ли обслуживания |
| Ключ в панели «пропал» | панель показывает маску; значение в `.env` на сервере |

## 8. Что не обсуждается

1. Оповещения об угрозах бесплатны всегда.
2. Реклама не появляется в тревожных сообщениях.
3. Без подтверждённой географии тревога не отправляется.
4. Событие в прошлом — сводка, а не тревога.
5. Терминала сервера в веб-панели нет.
6. Формулировка «не заменяет официальные каналы оповещения» остаётся везде.
