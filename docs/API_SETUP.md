# Настройка внешних сервисов

Пошаговые инструкции для всего, что бот использует снаружи: ключи ИИ,
источники, загрузка видео, погода и карты.

**Быстрый путь:** большинство ключей задаются прямо в боте — «🛠 Управление» →
«🔑 Ключи доступа» (только суперадминистратор). Значения пишутся в `.env`,
маскируются при показе, часть применяется сразу, часть — после перезапуска
контейнера. Ниже описано, где эти ключи взять.

## 1. Telegram: токен бота

**Нужен всегда.** Без него бот не запустится.

1. Откройте [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Задайте отображаемое имя и юзернейм (должен оканчиваться на `bot`).
3. Скопируйте токен вида `123456789:AAE...`.
4. Впишите в `.env`: `BOT_TOKEN=...`

**Свой Telegram ID** — у [@userinfobot](https://t.me/userinfobot), в `.env`
как `SUPERADMIN_ID`. Этот пользователь получает полные права.

Если токен утёк — `/revoke` у @BotFather, старый перестанет работать.

## 2. Google Gemini

Основной провайдер: разбор новостей и ИИ-ассистент. Без ключа бот работает
на эвристике по ключевым словам — оповещения продолжают приходить, но точность
ниже.

1. Откройте [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Войдите в аккаунт Google, нажмите **Create API key**.
3. Скопируйте ключ и вставьте в боте: «Ключи доступа» → «ИИ» → «Google Gemini».

**Ограничения бесплатного тарифа** — порядка 10 запросов в минуту и несколько
сотен в сутки. Бот их учитывает: `AI_RPM`, `AI_RPD`, плюс резерв `AI_RESERVE`
специально под ассистента, чтобы фоновый разбор не съедал квоту диалога.
Текущий расход — команда `/quota`.

**Выбор модели.** `/models` показывает всё, что доступно вашему ключу.
Закрепить конкретную:

```
/setmodel gemini-3.6-flash                  — для ассистента
/setmodel gemini-3.5-flash-lite analysis    — для разбора новостей
```

Действует сразу; чтобы сохранилось после перезапуска, задайте `GEMINI_MODEL`
и `GEMINI_MODEL_ANALYSIS` в «Ключах доступа».

Модели периодически отключают. Бот сам переходит на следующую доступную,
но список стоит поглядывать: Google закрыл `gemini-2.5-flash` для новых
ключей раньше объявленной даты.

## 3. Другие провайдеры ИИ

Нужны для сравнения и как запасной вариант. Проверка запускается в боте:
«🛠 Управление» → «🧪 Проверка ИИ».

| Провайдер | Где получить ключ | Особенности |
|---|---|---|
| **Groq** | [console.groq.com/keys](https://console.groq.com/keys) | быстрый, щедрый бесплатный тариф |
| **Cerebras** | [cloud.cerebras.ai](https://cloud.cerebras.ai) | около миллиона токенов в сутки |
| **Mistral** | [console.mistral.ai](https://console.mistral.ai) | Франция; всего 2 запроса в минуту |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | один ключ на десятки моделей |
| **DeepSeek** | [platform.deepseek.com](https://platform.deepseek.com) | самая низкая цена; можно сделать основным |
| **Z.ai / GLM** | [z.ai](https://z.ai) | часть моделей бесплатна |
| **Kimi** | [platform.moonshot.ai](https://platform.moonshot.ai) | до 1000 запросов в сутки |
| **Qwen** | [modelstudio.console.alibabacloud.com](https://modelstudio.console.alibabacloud.com) | международный эндпоинт |

**Смена основного провайдера.** «🛠 Управление» → «🤖 Провайдер ИИ»: Gemini
или DeepSeek. Перед переключением бот запрашивает баланс — у DeepSeek оплата
по факту, и ключ с нулевым остатком иначе выяснился бы на первой же тревоге.
Смена действует со следующего разбора.

**На что смотреть в результатах.** Не на общую точность, а на колонку
**«военные темы»**: провайдер, который отказывается разбирать сообщения
о БПЛА, для оповещений непригоден, каким бы точным он ни был в остальном.
Проверка прогоняет два таких кейса специально.

Второй момент — **доступность из вашей сети**. Часть площадок блокирует
российские адреса; если провайдер отвечает «таймаут», дело обычно в этом,
и помогает прокси (раздел 9).

## 4. ВКонтакте: чтение сообществ

Позволяет читать стены открытых сообществ — полезно, потому что ведомства
дублируют туда публикации из Telegram.

1. Откройте [vk.com/apps?act=manage](https://vk.com/apps?act=manage) →
   **Создать приложение** → тип **Standalone**.
2. В настройках приложения найдите **Сервисный ключ доступа**.
3. Вставьте в боте: «Ключи доступа» → «Источники» → «ВКонтакте».

Сервисного ключа достаточно: он даёт чтение открытых данных без входа
пользователя.

**Подводные камни**, которые бот обрабатывает: VK отвечает кодом 200 с телом
ошибки вместо 429; код 6 — слишком часто, код 9 — флуд-контроль; пустой
массив без ошибки не означает «новостей нет».

## 5. Одноклассники

Сложнее остальных: публичных RSS у OK нет, а API требует регистрации
приложения и подписи каждого запроса.

1. Зарегистрируйтесь на [apiok.ru](https://apiok.ru) и создайте приложение.
2. Дождитесь подтверждения — оно не мгновенное.
3. Получите три значения: **application key** (публичный),
   **access token** и **secret key**.
4. Впишите их в боте: «Ключи доступа» → «Источники».

Без ключей источник просто отключается и не мешает остальным.

Разбор HTML-страниц вместо API мы не используем: он ненадёжен и противоречит
правилам площадки.

## 6. Свой Bot API Server: файлы до 2 ГБ

Нужен только для загрузки видео. Обычный Bot API отдаёт от ботов файлы
не больше **50 МБ** — обойти это кодом нельзя.

1. Откройте [my.telegram.org](https://my.telegram.org), войдите по номеру
   телефона.
2. **API development tools** → создайте приложение (название любое).
3. Скопируйте **api_id** (число) и **api_hash** (строка).
4. Впишите в боте: «Ключи доступа» → «Медиа», а также
   `TELEGRAM_API_SERVER=http://telegram-bot-api:8081`.
5. В `.env` поставьте `MEDIA_ENABLED=1`.
6. Перезапустите с профилем:

```bash
cd ~/radar_bot
docker compose --profile media up -d
```

Установщик поднимет профиль сам, если увидит `MEDIA_ENABLED=1` и оба ключа.

**Важно:** `api_id` и `api_hash` привязаны к вашему аккаунту Telegram — это
не то же самое, что токен бота. Не публикуйте их.

Кэш сервера чистится сам: файлы старше 6 часов и при заполнении диска.

## 7. Мессенджер MAX

⚠️ **Адаптер реализован, но не проверен на живом сервере.** Включайте только
для испытаний: флаг `platform_max` в «Возможностях».

1. Зарегистрируйтесь в кабинете разработчика MAX (dev.max.ru или бизнес-кабинет).
2. **Пройдите верификацию владельца** — Госуслуги, Alfa ID, Т-Business ID или
   СберБизнес ID. Публиковать ботов могут только юрлица, ИП и самозанятые РФ.
3. Получите токен через `@MasterBot` командой `/create`.
4. Впишите `MAX_BOT_TOKEN` в `.env`.
5. Проверьте `MAX_API_URL`: в документации встречаются
   `platform-api.max.ru` и `platform-api2.max.ru`.

Модерация занимает до 48 часов в рабочие дни. Для боевой работы MAX требует
webhook — понадобится белый IP и HTTPS; long polling годится для проверки.

**Ограничение платформы:** читать чужие публичные каналы в MAX нельзя. API
бот-центричный: `chat_id` приходит только после того, как владелец добавит
вашего бота в свой канал. Поэтому MAX — канал доставки, а не источник новостей.

## 8. Погода и карты: без ключей

Ничего настраивать не нужно.

- **Open-Meteo** — погода и прогноз, работает без регистрации.
- **Nominatim (OpenStreetMap)** — определение адреса по координатам.

У Nominatim есть условие: **не чаще одного запроса в секунду**. Бот его
соблюдает. При большом числе пользователей имеет смысл поднять свой экземпляр.

## 9. Выход в сеть через свой узел

Пригодится, если провайдер ИИ или источник недоступен из вашей сети.
Настраивается целиком в боте, править `.env` вручную не нужно.

1. «🛠 Управление» → «🌐 Выход в сеть» → «Добавить ключ или подписку».
2. Пришлите одно из: ссылку на подписку, `vless://`, `ss://`, `trojan://`
   или `socks5://host:port`.
3. **Выберите сервер.** Это отдельный шаг: из подписки приходят десятки
   узлов, и пока конкретный не выбран, трафик идёт напрямую.
4. Нажмите «Включить выход».
5. Поднимите профиль на сервере:

```bash
cd ~/radar_bot
docker compose --profile proxy up -d
```

Бот сам пишет конфигурацию в `data/singbox/config.json`. Поддерживаются
VLESS (в том числе Reality), Shadowsocks, Trojan, SOCKS5 и HTTP.

Кнопка «Обновить подписку» перечитывает список. Если выбранный сервер из неё
исчез, выход выключается и бот об этом сообщает — молча переключаться
на другой узел он не будет.

Этот же выход используется для загрузки видео.

## 10. Оплата подписки на подборки

Отдельный платёжный сервис не нужен: Telegram Stars — встроенный механизм.

1. Ничего не подключайте — оплата работает сразу.
2. Тарифы задаются в боте: «📰 Новостные подборки» → «💰 Тарифы и оплата»
   (только суперадминистратор). Формат «дни:звёзды».
3. Звёзды зачисляются **на баланс самого бота**. Посмотреть:
   @BotFather → выбрать бота → Payments.
4. Вывод — через [Fragment](https://fragment.com), но не раньше чем через
   21 день после оплаты. Это правило Telegram, а не системы.
5. Возвраты выполняет поддержка Telegram по обращению пользователя;
   бот в этом не участвует.

Минимальная цена — одна звезда: счёт дешевле Telegram не примет.

## 11. Проверка настроек

**В боте:**

```
/models        какие модели Gemini доступны ключу
/quota         расход квоты Gemini
/bench         сравнение провайдеров ИИ
/checksources  доступность источников
/logs          журналы бота и установки
```

**На сервере:**

```bash
cd ~/radar_bot
docker compose run --rm radar python -m radar.doctor   # полная диагностика
docker logs -f radar_container                          # что происходит сейчас
bash collect-logs.sh                                    # все журналы в архив
```

Диагностика проверяет зависимости, конфигурацию, базу, полный цикл записи
и чтения, разбор старых данных и доступ к Telegram. Установщик запускает
её до старта бота: при ошибке бот не поднимается, а вы получаете отчёт.

## Что делать при утечке ключа

1. **Токен бота** — `/revoke` у @BotFather, затем новый в `.env`.
2. **Gemini** — удалить ключ в AI Studio, создать новый.
3. **api_id / api_hash** — сменить нельзя, они привязаны к аккаунту;
   при подозрении обращайтесь в поддержку Telegram.
4. **Пароль базы** — сменить в `.env`; при PostgreSQL придётся пересоздать
   том, пароль задаётся только при инициализации.

Файл `.env` хранится с правами 600 и не попадает в git — это прописано
в `.gitignore`. В журналы установки секреты не пишутся, в архиве
`collect-logs.sh` они вырезаются.
