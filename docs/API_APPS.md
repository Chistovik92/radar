# API для приложений HydraVPN

Для авторов приложений: **HydraVPN** (Android) и **HydraVPN for Routers**
(демон на Go). С 5.9.1. Роадмап — раздел «5.9.1» в [ROADMAP.md](ROADMAP.md).

Приложение подключается к аккаунту человека в боте и **читает** выданные
ему подписки. Выдаёт и отзывает доступ только суперадминистратор в боте —
через API этого сделать нельзя.

## Включение на сервере

1. `/features` → включить «Веб-панель» и «API для приложений HydraVPN»
   (флаги `web_panel`, `app_api`), перезапустить контейнер.
2. Наружу API открывают **только за HTTPS** (`WEB_HTTPS=1`, обратный прокси,
   как и панель): токен и ссылки подписок идут в заголовках и теле.
3. Адрес сервера — тот же, что у панели (`SHORT_BASE_URL`, если задан);
   бот показывает его вместе с кодом.

Пока флаг `app_api` выключен, все маршруты отвечают `404`.

## Как приложение входит

1. Человек в боте: «🔐 VPN» → «📱 Подключить приложение». Кнопка есть
   только у тех, кому доступ уже выдан. Бот показывает 8-значный код
   на 5 минут и адрес сервера.
2. Приложение: `POST /api/v1/app/link` с кодом → токен устройства.
   Токен показывается **один раз**, хранить его нужно в защищённом
   хранилище (Android Keystore, файл `0600` на роутере).
3. Дальше все запросы — с `Authorization: Bearer <токен>`.
4. Токен живёт, пока устройство не отключат: в боте («🔌 Отключить все
   устройства»), кнопкой в приложении (`DELETE /session`) или когда его
   вытеснят (пять устройств на человека, старейшее уходит первым).

## Маршруты

Ответы — JSON, заголовок `Cache-Control: no-store`.
Ошибка: `{"error": "текст"}` и код 4xx.

| Метод | Путь | Тело / ответ |
|---|---|---|
| GET | `/api/v1/app/ping` | `{"api": 1, "service": "radar"}` — без токена, проверка адреса |
| POST | `/api/v1/app/link` | `{"code": "12345678", "device": "Pixel 8", "app": "hydravpn"}` → `201 {"token": "…", "device_id": "a1b2c3d4"}` |
| GET | `/api/v1/app/me` | профиль и состояние VPN |
| GET | `/api/v1/app/subscriptions` | выданные подписки |
| DELETE | `/api/v1/app/session` | отключить это устройство |

`app` — `hydravpn`, `hydravpn-router` или любое другое (запишется как
`other`); `device` — подпись для списка в боте, до 40 знаков.

### `GET /me`

```json
{
  "user_id": "123456789",
  "username": "ivan",
  "blocked": false,
  "vpn": {"enabled": true, "state": "active", "panels": 2},
  "device": {"id": "a1b2c3d4", "name": "Pixel 8", "app": "hydravpn"}
}
```

### `GET /subscriptions`

```json
{"subscriptions": [{
  "panel": "1",
  "title": "Главный",
  "kind": "3xui",
  "link_kind": "subscription",
  "state": "ok",
  "enabled": true,
  "expire": 1900000000,
  "traffic_limit": 10737418240,
  "traffic_used": 524288000,
  "url": "https://sub.example/xyz"
}]}
```

* `expire` — unix-время окончания, `0` — бессрочно;
  `traffic_limit` — байты, `0` — без предела.
* `link_kind`: `subscription` (ссылка подписки — её и импортируют),
  `key` (один ключ, Outline), `config` (файл настроек, wg-easy).
* `state`: `ok`; `no_link` — запись есть, ссылку панель не отдала;
  `panel_error` — панель сейчас недоступна (повторить позже, остальные
  записи в ответе рабочие); `missing` — записи в панели больше нет.
* Пустой список — доступ не выдан, заблокирован или раздел VPN выключен.

## Коды ответов

| Код | Когда |
|---|---|
| 201 | код принят, токен выдан |
| 400 / 413 | тело не JSON / слишком велико |
| 401 | нет заголовка, токен не подошёл или отключён; код неверный или устарел |
| 404 | `app_api` выключен |
| 429 | слишком много неудачных попыток с адреса (десять за десять минут, тот же счётчик, что у входа в панель); подождать |

## Что делает приложение с ответом

* **HydraVPN (Android).** Экран «Аккаунт бота»: адрес сервера и код →
  `/link` → раз в несколько часов `/subscriptions`; каждую запись
  с `link_kind = subscription` завести как подписку (`url`), обновлять
  при смене `url`, скрывать при `enabled = false`.
* **HydraVPN for Routers.** Демон вызывает `/subscriptions` и добавляет
  ссылки своим API (`POST /api/v1/subscriptions`, см.
  [docs/API.md](https://github.com/Chistovik92/HydraVPNforRouters/blob/main/docs/API.md)
  этого репозитория). Токен бота хранится рядом с `api-token` роутера
  с правами `0600`.

Ссылки подписок и токены нельзя писать в журналы приложения — так же, как
и в журналы бота.

Пример:

```bash
BASE=https://radar.example.org/api/v1/app
TOKEN=$(curl -s -d '{"code":"12345678","device":"router","app":"hydravpn-router"}' \
        -H 'Content-Type: application/json' $BASE/link | jq -r .token)
curl -s -H "Authorization: Bearer $TOKEN" $BASE/subscriptions
```

## Границы

* API ничего не выдаёт, не продлевает и не отзывает.
* Права роли (модератор, администратор) через API не выдаются и не
  показываются: он отвечает только за подписки человека.
* Не проверено с настоящими приложениями и панелями — только
  `tests/test_appapi.py` и `tools/app_http_check.py`.
