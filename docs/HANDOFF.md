# Передача проекта

Документ на случай, когда работа продолжается в новом чате, другом аккаунте
или другим человеком. Цель — чтобы контекст восстанавливался за одно
сообщение, а не за час пересказа.

---

## Что нужно передать

**Всё существенное уже в репозитории.** Переписка не нужна: код, решения
и их обоснования лежат в файлах.

| Что | Где |
|---|---|
| Текущее состояние, решения, блокеры | `docs/STATUS.md` |
| Что и в какой версии делается | `docs/ROADMAP.md` |
| Настройка всех внешних сервисов | `docs/API_SETUP.md` |
| Устройство новостных подборок | `docs/NEWS_DIGEST.md` |
| План заработка | `docs/MONETIZATION.md` |
| Правила проекта для ассистента | `CLAUDE.md` |

---

## Первое сообщение в новом чате

Достаточно такого:

> Продолжаем проект «Радар» — Telegram-бот мониторинга городских угроз.
> Репозиторий: https://github.com/Chistovik92/radar
> Читай `docs/STATUS.md` и `docs/ROADMAP.md`, дальше работаем по карте.
> Отвечай по-русски.

Если репозиторий закрытый — приложите архив проекта файлом. Он собирается
командой:

```bash
cd radar && git archive --format=tar.gz -o radar.tar.gz HEAD
```

## Что перенести из настроек аккаунта

1. **Память ассистента.** В старом чате попросите выгрузить память одним
   блоком, в новом вставьте через Settings → Memory → Add to memory.
   Так переедут предпочтения: язык ответов, стиль работы, контекст проектов.
2. **Экспорт данных** — Settings → Privacy → Export data. Ссылка приходит
   на почту и живёт сутки. Пригодится как архив переписки, но для работы
   не требуется.
3. **Ссылка на чат** — меню Share. Делайте до переезда в организацию:
   при миграции в Team или Enterprise публичные ссылки перестают работать.

Ни один из способов не восстановит диалог как живой чат — вы получите текст,
который можно приложить файлом.

## Чего в репозитории нет и не должно быть

- `.env` с токенами и ключами — он в `.gitignore`.
- `data/` с базой и журналами.
- Резервные копии из `backups/`.

Их переносят отдельно и вручную:

```bash
# на старом сервере
cd ~/radar_bot
bash install.sh --backup        # копия базы, .env и данных

# на новом
scp radar-backup-*.tar.gz new-server:~/
```

## Состояние на момент передачи

**Версия 5.9** (сентябрь 2026). Работает на ARM-одноплатнике (RK3318)
за домашним роутером с белым IP, база SQLite, бот `@SecretHeroBot`, город
Саратов. Каждая версия выходит релизом на GitHub сама: `release.yml`
после зелёного CI на `main` (с 5.0, по каждой версии истории — с 5.6).

**Готово:** оповещения по адресам, отбой опасности, погода текстом
и картинкой, SOS с доверенными контактами, история событий, новостные
подборки с пересказами ИИ и подпиской, тихие часы, антиспам, загрузка
видео и картинок, выход в сеть через свой узел, смена провайдера ИИ,
веб-панель с темами и обновлением, ВКонтакте как источник, партнёрские
проекты, сокращение и проверка ссылок, модерация групп, музыка (в том
числе в облаке через rclone), два языка интерфейса, часовые пояса,
переезд на другой сервер, установка любой версии и откат, копии
по расписанию. С 5.0 — VPN: десять видов панелей, несколько сразу,
выдача только суперадминистратором, продажа по тарифам через сменный
платёжный слой (ручное подтверждение и Crypto Pay). 5.5 — Discord
как канал сообщества. 5.6–5.7 — один аккаунт во всех сетях: Telegram,
ВКонтакте, MAX и Discord, адреса можно задать в любой, тревоги приходят
во все связанные; вход в веб-панель по коду из бота. 5.8 — привязка
к аккаунтам клиентов VPN-панелей, заведённых руками или другим ботом.
5.9 — переход между SQLite и PostgreSQL с данными, в обе стороны.

**Дальше по карте:** пронумерованные пункты закрыты. Открыты
Одноклассники (7.0, пункт 2 — по условию карты после сезона работы ВК)
и раздел «Дальше — обсуждается»: Mini Apps, выгрузка сводок для
управляющих компаний, новые города, замена ИИ-провайдера по стенду
`bench/`.

**Что считается непроверенным.** Переезд на другой сервер написан
и по частям испытан, но целиком на чистой машине не проходился ни разу —
до этого его следует считать неработающим. То же с восстановлением
из копии: механизм есть, учебной тревоги не было. Всё из 5.x — VPN-панели,
Crypto Pay, Discord, ВКонтакте, MAX, вход в панель по коду — проверено
только тестами и эмуляторами (`tools/*_http_check.py`), не на живых
сервисах.

**Отложено осознанно:** всё, что требует чужой верификации или ключей,
которых пока нет. Писать такой код вслепую — значит выдавать непроверенное
за готовое.

## Как проверять изменения

Перед каждым коммитом — полный список из [CLAUDE.md](../CLAUDE.md),
кратко:

```bash
python3 -m unittest discover -s tests   # больше 1600 тестов, без сети
python3 tools/stubcheck.py              # импорт всех модулей + рантайм-проверки
python3 tools/lint_names.py             # сверка имён между модулями
python3 tools/lint_undefined.py         # обращения к неопределённым именам
python3 tools/lint_pyversion.py         # совместимость с Python из образа
python3 tools/lint_docker.py            # Dockerfile против .dockerignore
python3 tools/stamp_headers.py --check  # подпись автора
python3 tools/build_installer.py        # пересборка install.sh
bash -n install.sh                      # синтаксис установщика
python3 tools/lint_shellorder.py        # вызов функции раньше определения
python3 tools/lint_installer.py         # подстановки и словарь установщика
python3 tools/lint_release.py           # номер версии поднят везде
python3 tools/lint_manifest.py          # новые модули в манифесте
python3 tools/vpn_http_check.py         # VPN-панели по HTTP (нужен aiohttp)
python3 tools/discord_http_check.py     # Discord по WebSocket
python3 tools/vk_http_check.py          # ВКонтакте по HTTP
python3 tools/db_transfer_check.py      # перенос SQLite ⇄ PostgreSQL (PG_URL)
```

Плюс каждый файл тестов по отдельности.

Каждая из этих проверок появилась после реальной поломки на сервере —
и ловит именно её. Пропускать их не стоит.

## Что стоит знать о характере проекта

Это система оповещения об опасности. Отсюда несколько правил, которые
не обсуждаются:

1. **Оповещения об угрозах бесплатны всегда.** Платить можно только
   за новостные подборки.
2. **Реклама не появляется внутри тревожных сообщений.**
3. **Без подтверждённой географии тревога не отправляется** — лучше
   промолчать, чем разослать чужой регион.
4. **Событие в прошлом — не тревога**, а сводка.
5. **Формулировка «не заменяет официальные каналы оповещения»** остаётся
   везде: источники публичные, классификация вероятностная.
