# v5.6.1 — выпуск v5.5 и v5.6 после сбоя

Автоматический выпуск после слияния 5.5 и 5.6 упал с HTTP 403
«Resource not accessible by integration» на теге v5.5, и релиз v5.6
тоже не вышел: установщик (`install.sh --versions`) этих версий не видел.

## Причина

Встроенный `GITHUB_TOKEN` не вправе создавать ссылку на коммит, у которого
`.github/workflows` отличается от `main`: для GitHub это изменение
workflow. Коммит v5.5 был сделан до шага `vk_http_check` в CI.

## Что исправлено

- `tools/release_notes.py pending` сверяется со списком **релизов**,
  а не тегов: версия с тегом, но без релиза, выпускается на своём теге.
- Версия, куда токен тег поставить не может, пропускается с подсказкой
  в журнале, остальные выходят как обычно.
- `release.yml` не менялся — иначе и коммит v5.6 стал бы непомечаемым.

## Что сделать автору один раз

```bash
git fetch origin
git tag v5.5 b3bf676 && git push origin v5.5
```

После этого запустить Actions → Release → Run workflow (или дождаться
следующего слияния) — релиз v5.5 выйдет на готовом теге.

Оповещения об угрозах — бесплатно; бот не заменяет официальные каналы
оповещения.
