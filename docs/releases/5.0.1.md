# v5.0.1 — несколько VPN-панелей и выдача только суперадминистратором

Панелей теперь может быть несколько сразу и разных, а доступ к VPN не получает никто без решения суперадминистратора.

## 🔐 Несколько панелей, десять видов

До шести слотов (`VPN1_*` … `VPN6_*`, в разделе ключей — группы «VPN 1» … «VPN 6»), у каждого свой вид, адрес и вход:

| Панель | Что получает человек |
|---|---|
| 3x-ui 2.x и 3.x, x-ui (alireza0), s-ui | подписку |
| Marzban, PasarGuard, Marzneshin, Remnawave | подписку |
| Hiddify | страницу подключения |
| Outline | ключ `ss://` (сроков у Outline нет) |
| wg-easy | одноразовую ссылку на файл WireGuard (предела трафика нет) |

Обращения к разным панелям идут **параллельно**, и отказ одной не задерживает и не ломает остальные: выдача на три панели, из которых одна недоступна, выдаст на две и честно скажет про третью.

Не поддерживаются намеренно: **AmneziaVPN** (управляется по SSH, HTTP API для ключей у неё нет) и **голый Xray или sing-box** (не хранят пользователей).

## 🛡 Выдачу контролирует только суперадминистратор

- заявку видит и решает только суперадминистратор — администраторам и модераторам она не приходит;
- он отмечает, на какие панели выдать; ссылки приходят человеку в личку, по одной на панель;
- по каждой панели — продление, выключение и отзыв; проверка всех панелей разом.

Выдача по роли из 5.0 убрана вместе с `VPN_AUTO_ROLE`. Проверка роли стоит в самой логике выдачи, а не только на кнопках.

## 🩹 Исправлены клиенты 5.0

Клиенты 5.0 писались по документации. Сверка с исходным кодом самих панелей показала три расхождения:

- **3x-ui 3.x** убрала `addClient`/`updateClient`: клиент стал отдельной сущностью (`/panel/api/clients/...`), а вход по паролю требует CSRF-токен. Клиент 5.0 с новой 3x-ui не заработал бы. Теперь поддерживаются обе ветки, 2.x и 3.x, — определяются сами;
- **PasarGuard** ждёт ключ API в заголовке `X-Api-Key`, а не Bearer, и `0` для «бессрочно» при правке — `null` у неё значит «не менять»;
- **Remnawave** правит запись по `username` или числовому `id`, а не по `uuid`.

## 🔒 Самоподписанные сертификаты — без отключения проверки

`VPN{n}_CERT` — SHA-256 сертификата панели. Проверка при этом не отключается, а сводится к сравнению с отпечатком: так подключается Outline и 3x-ui на голом IP. Отключить проверку сертификата совсем нельзя.

## 🧪 Как проверено и как проверить

- 72 офлайн-теста: разметка запросов всех десяти панелей, параллельная работа, изоляция отказов, право решения только у суперадминистратора;
- `tools/vpn_http_check.py` (новый шаг CI) — настоящие клиенты по HTTP через эмуляторы десяти панелей, написанные по их исходникам: куки, CSRF, заголовки входа, закрепление сертификата, выдача через `radar/vpn.py` на все панели разом;
- на сервере: `python -m radar vpn check` (только чтение) и `python -m radar vpn selftest --yes` — полный круг на записи `radar_selftest`, которая остаётся выключенной.
