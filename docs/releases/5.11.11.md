# v5.11.11 — Страница «Наши проекты»: ещё два проекта команды

На странице `/projects` добавлены две новые карточки с проектами команды SecretHero.

## Новые проекты

- **winOpenCodeMod** — GUI-плагин для OpenCode Desktop, возвращающий форму «Custom provider» (как в v1.19.x) в раздел Settings → Providers. Добавление, правка и удаление собственных OpenAI-совместимых провайдеров без ручной правки `opencode.json`. TypeScript + Solid.js.
- **DataOpenCode** — безопасный аддитивный перенос провайдеров, моделей, API-ключей и диалогов OpenCode между Windows-компьютерами: экспорт в zip-архив и развёртывание на другой машине без перезаписи локальных настроек, поддержка V1 ↔ V2, защита ZIP и резервные копии.

Описания написаны по реальным README репозиториев.
