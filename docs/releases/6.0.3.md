# Релиз 6.0.3

**Дата:** 22 ноября 2026

## Исправлен роутинг музыкального каталога

Кнопка «🎵 Музыка» из главного меню теперь ведёт на новый музыкальный каталог вместо старого интерфейса локальной музыки.

### Изменения

- Флаг `music_search` включён по умолчанию (`default=True` в `radar/features.py`)
- Обработчик `mus:menu` в `radar/handlers/music.py` перенаправляет на `music_search.catalog_menu()` при включённом флаге
- Параметр `state` получается через dependency injection
- Меню каталога: 🏆 Топ / ⭐ Избранное / 🔍 Поиск / 🎵 Плейлисты / 🕘 История / 🎲 Случайный / 🏆 Топ плейлистов / 👤 Профиль / ℹ️ Помощь / ◀️ К моей музыке

### Технические детали

- `radar/handlers/music.py` строка 116: добавлен параметр `state` через DI
- `radar/features.py` строка 142: `music_search = Feature(..., default=True)`
- Версия согласована в `radar/__init__.py`, `README.md`, `README.en.md`, `docs/STATUS.md`, `CLAUDE.md` и лендинге

### Файлы

- `radar/__init__.py`: версия поднята до `6.0.3`
- `radar/handlers/music.py`: исправлен обработчик `mus:menu`
- `radar/features.py`: флаг `music_search` включён по умолчанию
- `README.md`, `README.en.md`, `docs/STATUS.md`, `CLAUDE.md`: обновлена версия
