# v5.9.4 — живые аккаунты в Telegram

## Что стало

- **Чистка удалённых аккаунтов** (флаг `deleted_cleanup`). В группе
  администратор пишет `/cleandeleted`, бот проверяет известных ему
  участников и по кнопке исключает удалённые аккаунты. Из консоли —
  `radarctl.sh chats clean -100… [--yes]`.
  Bot API не отдаёт список участников, поэтому проверяются только те, кого
  бот видел сам; отчёт показывает охват («известно X / Y»).
- **Тайм-аут капчи** (флаг `captcha_kick`). Не нажавший «Я не бот» за пять
  минут исключается (бан и сразу разбан), сообщение с кнопкой убирается.
- **Проверка по базе CAS** (флаг `cas_check`). Числовой идентификатор
  вступившего отправляется во внешний сервис Combot Anti-Spam. Найденный
  исключается до приветствия; при недоступности сервиса человека не
  блокируют.
- **Недоступные получатели.** Заблокировавшему бота и удалившему аккаунт
  тревоги больше не отправляются каждый цикл; отметка снимается, когда
  он пишет боту. `radarctl.sh users stale [--prune --yes]`.

Все три флага выключены по умолчанию.

## Не проверено

С живой группой и настоящим Bot API не пробовалось. Признак удалённого
аккаунта (имя «Deleted Account») — предположение по поведению Telegram.
