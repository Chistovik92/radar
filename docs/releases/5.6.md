# v5.6 — тревоги во ВКонтакте и MAX, решение по Viber и WhatsApp

Второй канал тревог для тех, кто настроил бота в Telegram: после привязки оповещения по адресам приходят ещё и во ВКонтакте или MAX.

## 🔗 Привязка и копии тревог

- в Telegram: «⚙️ Оповещения» → «🔗 Привязать ВК или MAX» (или `/link`) — шестизначный код на 10 минут;
- код отправляют боту во ВКонтакте или в MAX — с этого момента **тревоги по адресам приходят и туда**, копией того, что пришло в Telegram;
- адреса и настройки остаются в Telegram: география подтверждена там, поэтому правило «без подтверждённой географии тревога не отправляется» соблюдено;
- копия уходит фоновой задачей — Telegram её не ждёт, сбой ВК или MAX не задерживает и не роняет цикл оповещений;
- код выдаёт только Telegram: зная чужой id ВК, чужие тревоги к себе не направить; перебор ограничен пятью неверными кодами за 10 минут;
- `/unlink` в ВК или MAX либо кнопка в Telegram снимают привязку.

Это заодно закрывает открытый вопрос из раздела 6.0 карты — связывание аккаунтов Telegram и MAX.

## 💬 ВКонтакте как мессенджер

Возможность «ВКонтакте как мессенджер» (`platform_vk`), **по умолчанию выключена**. Бот сообщества работает через Bots Long Poll API — входящий адрес не нужен. Формат и коды сбоя сверены с исходниками vkbottle; ключ сообщества передаётся телом запроса, а не адресом.

## ❌ Viber и ⏸ WhatsApp

- **Viber отклонён**: с 5 февраля 2024 новые боты — только по договору с Rakuten, 115 € в месяц плюс оплата каждого сообщения по инициативе бота. Бесплатные тревоги на этом не построить. Источник: [Viber Bot commercial model](https://help.viber.com/hc/en-us/articles/15247629658525-Bot-commercial-model).
- **WhatsApp отложен**: с 1 июля 2025 Meta берёт плату за каждое шаблонное сообщение, без верификации бизнеса — предел 250 диалогов в сутки. Источник: [Meta pricing](https://developers.facebook.com/documentation/business-messaging/whatsapp/pricing/conversation-based-pricing).

## 🧪 Как проверено

- 25 офлайн-тестов: срок и одноразовость кода, защита от перебора, смена владельца, зеркало только для доставленного, фоновая отправка, коды сбоя Long Poll;
- `tools/vk_http_check.py` — новый шаг CI: по настоящему HTTP через эмулятор API ВКонтакте и Long Poll — сбои 1–3, привязка кодом, копия тревоги только привязанному, ключ не в адресе, остановка на ошибке 5.
