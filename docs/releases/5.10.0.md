# Radar v5.10.0 — Лендинг, публичные страницы и Telegram Mini App виджеты

**Дата релиза:** 2026-11-17

## Главные изменения

### Новый публичный лендинг (/)
Полностью переработана публичная страница проекта с современным дизайном и полной поддержкой Platega compliance:

- Hero — заголовок, CTA в бот, отображение версии
- Features — сетка из 8 возможностей системы
- How it works — 3 шага для понимания работы
- Demo — скриншоты интерфейсов бота и панели
- Documents — кнопки перехода к Privacy, Terms, Support, Pricing
- Installation — табы: Bash / Docker / Ручная установка
- TG Login Widget — вход через Telegram (data-size="large") с редиректом по ролям
- Footer — GitHub, лицензия, автор, скрытое кодовое слово mekbuda для модерации

### Публичные страницы для Platega compliance
Добавлены обязательные для платёжной системы Platega страницы (доступны без авторизации):

| Страница | Назначение |
|----------|------------|
| /privacy | Политика конфиденциальности |
| /terms | Условия использования |
| /support | Поддержка (контакты: @SecretHeroSupportBot / email) |
| /pricing | Цены и тарифы (лимит 10 000 ₽/транзакция) |

Все страницы адаптированы из шаблонов telegra.ph с данными проекта Radar.

### Telegram Mini App виджеты
Реализованы 3 виджета для встраивания в Telegram Mini Apps через /api/widget/*:

| Виджет | Эндпоинт | Описание |
|--------|----------|----------|
| Погода | /api/widget/weather | Текущая погода и прогноз |
| Новости | /api/widget/news | Лента новостей города |
| Опасность | /api/widget/danger | Статус угроз и аварий ЖКХ |

Виджеты используют Telegram Web App JS SDK (cdn.telegram-web-app.js) и рендерятся без авторизации.

### Telegram Login Widget с ролевым редиректом
На лендинге и в панели добавлен виджет входа через Telegram. После успешной авторизации пользователь перенаправляется по роли:

| Роль | Редирект |
|------|----------|
| user | /profile |
| moderator | /sources |
| admin | /users |
| superadmin | /settings |

## Технические изменения

### Новые модули
- radar/web/landing.py — рендеринг лендинга
- radar/web/public_pages.py — публичные страницы (Privacy, Terms, Support, Pricing)
- radar/web/widgets.py — API эндпоинты виджетов + JS-модуль

### Обновлённые модули
- radar/web/panel.py — добавлены маршруты публичных страниц, ролевой редирект в authenticate()
- radar/web/auth.py — используется существующая логика TG Login Widget + кодовая авторизация
- radar/__init__.py — версия обновлена до 5.10.0

### Исправления
- Устранён циклический импорт PAGE_STYLE между panel.py и public_pages.py (стили встроены локально)
- Убраны упоминания VPN/обфускации, персональных данных (Platega compliance)
- Добавлен лимит 10 000 ₽ на транзакцию

## Требуется настройка (BotFather)

Для работы Telegram Mini App виджетов и TG Login Widget необходимо настроить в BotFather:

1. Menu Button → Web App URL: https://<ваш-домен>/
2. Domain — добавить ваш домен
3. Privacy Policy URL — https://<ваш-домен>/privacy
4. Terms of Service URL — https://<ваш-домен>/terms
