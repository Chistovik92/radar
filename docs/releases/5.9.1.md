# v5.9.1 — API для приложений HydraVPN

Приложения **HydraVPN** (Android) и **HydraVPN for Routers** теперь могут
войти в аккаунт человека в боте и забрать выданные ему подписки.

## Как это выглядит

1. В боте: «🔐 VPN» → «📱 Подключить приложение» — одноразовый код
   на 5 минут и адрес сервера.
2. Приложение меняет код на токен устройства (`POST /api/v1/app/link`).
3. Читает профиль и подписки: ссылка, срок, трафик, состояние по каждой
   панели (`GET /api/v1/app/me`, `/subscriptions`).
4. Устройство отключается из бота или из приложения.

## Что важно

- **Только чтение.** Выдаёт, продлевает и отзывает доступ по-прежнему
  один суперадминистратор.
- Токен виден один раз, на сервере лежит только его SHA-256; пять
  устройств на человека.
- Флаг `app_api` выключен по умолчанию; нужен и `web_panel`. Наружу —
  только за HTTPS.
- Контракт для авторов приложений — `docs/API_APPS.md`. Сами приложения
  этим выпуском не менялись.
- С настоящими приложениями и панелями не проверялось; транспорт
  проверяет `tools/app_http_check.py`.
