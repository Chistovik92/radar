# v6.0.1 — RustDesk возвращён на latest

Образ RustDesk в `docker-compose.yml` снова `rustdesk/rustdesk-server:latest` вместо жёсткой привязки к `1.1.16`.

- Новые установки автоматически получают актуальный выпуск (сейчас 1.1.16, содержащий исправление CVE-2026-30784 — UDP reflection/amplification).
- Существующие установки обновляют образ вручную: `docker compose --profile rustdesk pull hbbs hbbr && docker compose --profile rustdesk up -d hbbs hbbr`.
