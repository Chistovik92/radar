# Версия 5.11.5 — React Router и расширенная система пасхалок HYDRA

**Дата релиза:** 19 ноября 2026

## Новые возможности

### React Router и новые страницы лендинга

- Добавлен React Router v7 для навигации между страницами лендинга
- Созданы страницы `/pricing`, `/privacy`, `/terms` с простым лейаутом (БЕЗ полноэкранной RadarScene)
- Компактная шапка с навигацией и маленьким логотипом TRISKELION в `PageLayout.tsx`
- Главная страница (`/`) сохранена в `App.tsx` без изменений структуры

### Расширенная система пасхалок HYDRA

- Добавлены **кодовые слова Зимнего Солдата** (Winter Soldier activation codes) из MCU в `data.ts`
- Добавлены **фразы активации HYDRA** ("Hail Hydra" и варианты) в `data.ts`
- Расширен `ZolaTerminal.tsx` для обработки всех триггеров HYDRA:
  - 3 клика по маленькому логотипу TRISKELION в шапке
  - Ввод кодовых слов Зимнего Солдата в терминале
  - Команда "Hail Hydra" в терминале
- **Whisper button** в `HudOverlay.tsx` для возврата управления интерфейсом

### Системные улучшения

- Компонент `Helicarrier.tsx` с патрулирующей траекторией
- Системное уведомление с механикой размножения окон
- Все стили для новых страниц добавлены в `landing/src/styles.css`

## Технические изменения

- **React Router**: `react-router@7.1.3`, `react-router-dom@7.1.3`
