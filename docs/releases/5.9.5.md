# v5.9.5 — проверка участников Discord

## Что стало

Флаг `discord_verify` (выключен). Надёжно доказать человека нельзя — у Discord
нет капчи для ботов, — проверка поднимает цену автоматического входа:

- кнопка «Я человек» → окно с вопросом (три попытки) → роль «проверен»;
- аккаунт, связанный через `/link` с проверенным в другой сети, проходит
  без вопроса;
- при вступлении (нужно намерение Server Members): слишком молодой аккаунт
  и имя с рекламой исключаются сразу, не прошедший вовремя — по тайм-ауту;
- команда `/verifysetup` ставит кнопку в канал проверки (видна только тем, кто
  управляет сервером);
- если привилегированное намерение не включено, бот откатывается к обычным и
  пишет причину в журнал: кнопка работает, остальное — нет.

Настройка роли и каналов — на стороне сервера Discord, шаги в README.

## Не проверено

С живым Discord не пробовалось; транспорт проверен по эмулятору,
написанному по исходникам discord.py. Внешняя капча на домене панели
не делалась.
