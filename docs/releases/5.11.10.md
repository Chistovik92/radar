# v5.11.10 — Страница «Наши проекты» дополнена десятью проектами команды

На странице `/projects` появились десять новых карточек с проектами команды SecretHero. Описания написаны по реальным README и описаниям репозиториев.

## Новые проекты

- **opendisk** — облачные хранилища как локальные диски на базе rclone (Windows, Linux, Android; Яндекс.Диск, Mail.ru, Google Drive, Dropbox, S3).
- **NeuroCode Android** — открытый клиент для LLM: запуск моделей на устройстве и для удалённого выполнения через консоль.
- **LocalDoc AI** — кроссплатформенная локальная читалка книг с нейросетями (Android + iOS): озвучка, RAG, OCR и синтез речи полностью на устройстве.
- **med-roster** — графики смен и расчёт табелей Т-13 для персонала поликлиники (импорт Excel, правка в браузере, выгрузка официальных форм).
- **MeshkitKeen** — управление mesh-сетью Keenetic с одного терминала (форк KeenKit).
- **torrserver-docker-manager** — Docker-менеджер TorrServer.
- **Harness** — десктоп-приложение на базе DeepSeek Harness: несколько LLM-провайдеров, локальная история, шифрование ключей API.
- **ZHeroDiZk** — открытая система удалённого доступа в классе RustDesk/AnyDesk.
- **servAI** — установщик AI-сервера одной командой (Claude Code, Codex CLI, Gemini CLI, Aider, веб-IDE).
- **zeropentime** — децентрализованная альтернатива ZeroTier на AmneziaWG 3.

У каждой карточки — иконка и ссылка на GitHub-репозиторий; блок «Раздел наполняется» заменён ссылкой на профиль SecretHero.
