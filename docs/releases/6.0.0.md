# v6.0.0 — CMS лендинга, музыкальный каталог и бот поддержки

Крупное обновление: суперадминистратор получает управление сайтом без правки кода, в бот добавлен поиск и прослушивание музыки, а рядом с основным ботом появляется отдельный тикет-бот поддержки.

## 🎛 CMS лендинга

- Суперадминистратор правит тексты и простые списки сайта через веб-панель. Контент хранится в `meta`: схемы с дефолтами, merge, безопасный рендер и лимиты полей.
- Структура и вёрстка фиксированы и через CMS не меняются — редактируются только тексты.

## 🎵 Музыкальный каталог

- Поиск по бесплатному каталогу: SoundCloud с резервом YouTube (включается флагом `music_search`).
- Прослушивание через Telegram `file_id` с кэшем в `meta` — без постоянного аудиоархива.
- Избранное, история, публичные плейлисты, топы, шаринг, реакции и inline-режим.
- DRM и премиум-превью исключаются. Персональное состояние хранится в `User.music` (миграция `0006_user_music`).

## 🛠 Бот поддержки

- Отдельный бот в `support/`: тикеты `#год-N`, топики в группе, вложения, 👍/👎, SLA и экспорт `.txt`.
- FAQ плюс опциональный Gemini (`support_ai`). Второй контейнер — сбой поддержки не мешает основному боту.
- Установщик опционально ставит оба бота.

## 🔒 Прочее

- Образ RustDesk остаётся `latest` (актуальный выпуск 1.1.16 с исправлением CVE-2026-30784).
- Лицензия Apache-2.0 для `not_a_music` в `licenses/`.
- Исправлен `stamp_alembic()`: после автообновления Alembic отмечает фактический head.
