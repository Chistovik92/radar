# Radar v5.11.0 — Интерактивный орбитальный сайт

**Дата релиза:** 2026-11-18

## Сайт проекта

Публичная страница `/` переписана на React 18, TypeScript, Vite и Tailwind.
Она показывает реальные возможности «Радара»: адресные оповещения, погоду,
новости, тихие часы, подписку и приватную инфраструктуру. Самостоятельная
установка из лендинга убрана. Тарифы, описание и username бота приходят из backend.
Локация посетителя определяется приблизительно по IP через `/api/widget/location`;
её город и координаты используются в виджетах погоды и опасности, точный адрес
и сам IP не выводятся.

## Орбитальная сцена

- GLSL черная дыра с аккреционным диском, линзированием и кольцом Эйнштейна;
- шесть планет и станций, представляющих функции мониторинга;
- 180 InstancedMesh-астероидов и семь процедурных щупалец;
- событие поглощения каждые 45–60 секунд и замещение узла `-ALPHA`/`-OMEGA`;
- секретный ZOLA ALGORITHM // PROJECT INSIGHT, журналы и ELEVATOR_PROTOCOL;
- адаптивная компоновка, клавиатурный фокус и `prefers-reduced-motion`.

Пасхалки меняют только визуализацию и не представляют вымышленный продукт.

## Интеграция и совместимость

`cd landing && npm ci && npm run build` создаёт `landing.js` и `landing.css`
в `radar/web/static/landing`. Эти предсобранные файлы включены в Docker-образ
и автономный установщик: Node.js на сервере не требуется. Маршрут
`/landing/{asset}` принимает только два известных имени файла.

Сохранены `/login`, Telegram Login Widget, `/auth`, `/profile`, код `/panel`,
ролевые редиректы, публичные документы и `/api/widget/*`.

## Проверки

- TypeScript и production Vite build;
- тест HTML-конфигурации и экранирования описания;
- контракты публичных страниц и виджетов;
- CLI parity и release/installer linters.

WebGL, Telegram Login и сетевые виджеты требуют финальной проверки в браузере
на настроенном домене.
