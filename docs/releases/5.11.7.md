# Версия 5.11.7 — страница поддержки и живые виджеты с геолокацией

**Дата релиза:** 19 ноября 2026

## Что сделано

Три изменения в одной версии: страница поддержки переведена на лендинг,
геолокация на виджетах стала трёхступенчатой, а виджет «Статус опасности»
теперь показывает последнее событие БПЛА/МЧС для локации посетителя.

### 1. `/support` в стиле лендинга

- Страница поддержки переведена с серверного `public_pages.render_support_page`
  на SPA-оболочку лендинга — та же 3D-сцена и навигация, что у `/pricing`,
  `/privacy` и `/terms`.
- Контент перенесён в `landing/src/pages/Support.tsx`: каналы поддержки
  (тикет-бот, прямой контакт, email), SLA по времени ответа, «что ускорит
  помощь», FAQ.
- Ссылки на `/support` в навигации и футере переведены с `<a href>` на
  `<Link>` — переходы теперь не перезагружают страницу.

### 2. Определение города по IP: три ступени

Порядок определения локации посетителя (в `radar/web/widgets.py`):

1. **ip-api.com** (основной) — бесплатный, без ключа, но доступен только по
   HTTP; запрос идёт с сервера бота, а не из браузера, поэтому смешанного
   контента на HTTPS-странице нет.
2. **ipwho.is** (запасной) — HTTPS, используется если ip-api.com недоступен
   или не нашёл адрес.
3. **Точная геолокация браузера** (`navigator.geolocation`) — если оба сервиса
   не дали город. Координаты превращаются в город новым endpoint'ом
   `/api/widget/reverse` (reverse geocode через Nominatim, кэшируется).

Приватные и локальные адреса наружу не передаются (проверка `ip.is_global`),
точный адрес пользователя не запрашивается.

### 3. Виджет «Статус опасности» с последним событием

- `widget_danger` теперь принимает `lat`/`lon` (как и погода): город
  определяется по координатам либо по IP.
- Новый `repo.latest_threat(city)` возвращает последнее событие БПЛА/МЧС по
  городу (тип, серьёзность, время, сводка, признак отбоя).
- Виджет показывает тип и время последнего события; при отсутствии данных
  за окно наблюдения — «опасность не обнаружена».

## Свободные сервисы IP-геолокации (оценка)

| Сервис | Протокол | Ключ | Лимит без ключа | Статус в проекте |
| --- | --- | --- | --- | --- |
| ip-api.com | только HTTP | нет | 45 запросов/мин | основной |
| ipwho.is | HTTPS | нет | не документирован | запасной |
| ipinfo.io | HTTPS | да | 50k/мес с токеном | не используется |
| ipapi.co | HTTPS | нет | 1000/день | не используется |

Выбран связка ip-api.com → ipwho.is как самая простая: оба без ключа, ответы
уже нормализованы в `_lookup_ip_api`/`_lookup_ipwhois` к одному виду.

  событие)

- `landing/src/components/PageLayout.tsx`, `App.tsx`, `pages/Pricing.tsx` —

- `landing/src/components/LiveWidgets.tsx` — геолокация в виджете опасности,

- `landing/src/styles.css` — стили карточек поддержки и кнопки геолокации
- `tests/test_web_public.py` — тесты нового порядка локации и последнего события
- `radar/__init__.py`, `main.py`, `install.sh`, документация — версия 5.11.7
