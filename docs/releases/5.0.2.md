# v5.0.2 — продажа VPN по тарифам и платёжный слой

Пункты 4 и 5 блока 5.0: доступ к VPN можно продавать по тарифам, а деньги принимает сменный провайдер. Оповещения об угрозах этим не затрагиваются — они бесплатны всегда.

## 💳 Тарифы

Возможность «Продажа VPN» (`vpn_sales`), **по умолчанию выключена** — продажи включает только суперадминистратор.

Тарифы — строка `VPN_PLANS` в разделе ключей: `дни:трафикГБ:устройства:цена` через точку с запятой, например `30:0:3:199; 90:0:3:499`, где `0` — без предела. Валюта — `VPN_CURRENCY` (по умолчанию RUB), панели для продажи — `VPN_PLAN_SLOTS`.

- оплата **продлевает тот же ключ** и прибавляет дни к оставшимся — перенастраивать устройства не нужно;
- заказ переходит «ждёт оплаты → оплачен → выдан» один раз под замком: **двойное «Я оплатил» не выдаёт доступ дважды**;
- цена замораживается в заказе: смена тарифов, пока человек платит, не меняет того, за что он платит;
- панель не ответила — заказ остаётся оплаченным, у суперадминистратора появляется кнопка «Повторить выдачу»;
- предел устройств действует там, где он есть у панели: 3x-ui и x-ui (`limitIp`), Remnawave (`hwidDeviceLimit`).

## 💰 Платёжный слой

Провайдер задаётся `PAY_PROVIDER` и меняется, не трогая продажи:

- **manual** — бот денег не принимает: человек платит так, как указано в `PAY_MANUAL_NOTE`, суперадминистратор подтверждает оплату кнопкой. Работает без оформления где-либо;
- **cryptopay** — Crypto Pay (@CryptoBot): счёт в Telegram, оплата криптовалютой, бот сверяет состояние счёта по кнопке «Я оплатил». Регистрации продавца не требует. Есть тестовая сеть (`PAY_CRYPTOPAY_TESTNET=1`).

Бесплатно доступ по-прежнему выдаёт только суперадминистратор: путь продаж даёт только оплаченный срок.

## 🧪 Как проверено

- 28 новых офлайн-тестов: разбор тарифов, подделанная кнопка тарифа, два «Я оплатил» одновременно, продление с прибавлением дней, частичный отказ панелей, ручное подтверждение только суперадминистратором, подпись webhook;
- `tools/vpn_http_check.py` дополнен эмулятором Crypto Pay: покупка по настоящему HTTP — счёт, оплата, двойная проверка, продление на четырёх панелях.

⚠️ **Что остаётся непроверенным.**
- Формат Crypto Pay сверен с исходниками клиента `aiocryptopay`: официальная документация из среды разработки недоступна.
- **Комиссия, лимиты и условия вывода Crypto Pay не проверены** — посмотрите их в @CryptoBot до включения продаж.
- С настоящими платежами и панелями не запускалось: начните с `PAY_CRYPTOPAY_TESTNET=1`.
- Webhook Crypto Pay не подключён: у бота нет входящего адреса, оплата сверяется по кнопке.
