# Монетизация «Радара» — варианты и оценки

Документ для обсуждения, не план работ. Ничего из перечисленного в коде пока нет,
кроме партнёрской кнопки в главном меню.

## Что уже есть в v3.3.0

Кнопка партнёра в главном меню и блок в разделе «О системе». Настраивается
без правки кода:

```env
PROMO_ENABLED=1
PROMO_TITLE=🛡 HydraVPN — обход блокировок
PROMO_URL=https://t.me/+WWJFBZVhxBs4ZmNi
PROMO_TEXT=...
PROMO_IN_ALERTS=0
```

`PROMO_IN_ALERTS` по умолчанию выключен намеренно. Реклама внутри оповещения
о ракетной опасности читается как заработок на тревоге и бьёт по доверию —
а доверие здесь и есть главный актив. Кнопка в меню и упоминание в разделе
«О системе» дают тот же охват без этой цены.

## 1. Партнёрство с HydraVPN

Самый естественный путь: связка «белые списки → нужен VPN» возникает сама.
Пользователь получает предупреждение об ограничении мобильного интернета
и в этот момент как раз ищет решение.

**Как усилить, не переходя черту:**

- Отдельный раздел «Что делать при ограничениях связи» — там уместно и полезно.
- Промокод в боте: `/vpn` выдаёт код и ссылку, по коду считается конверсия.
- Deep link с меткой: `https://t.me/HydraVPNbot?start=radar_<uid_hash>` — так
  видно, сколько регистраций пришло из «Радара», без передачи персональных данных.

**Взаимодействие ботов** (на будущее): «Радар» не должен ходить в чужую базу.
Достаточно подписанной ссылки — «Радар» формирует токен с меткой источника,
бот HydraVPN проверяет подпись общим секретом и начисляет бонус. Никакого
общего хранилища, никакой зависимости по доступности: если один бот лежит,
второй работает.

**Осторожно с юридической стороной.** Реклама средств обхода ограничений
в РФ регулируется, и формулировки лучше согласовать. «Защита соединения
в публичных сетях» и «обход блокировок» — разные тексты с разными рисками.
Это ваша зона решения, я просто отмечаю, что она есть.

## 2. Freemium внутри бота

Базовая функция — оповещения — должна остаться бесплатной. Это вопрос не
только этики: платная тревога о БПЛА отпугнёт аудиторию, на которой держится
всё остальное.

| Бесплатно | Платно |
|---|---|
| до 3 локаций | без ограничений |
| оповещения ЖКХ, БПЛА, МЧС | история событий по адресу за месяц |
| погода по расписанию | точное время + расширенный прогноз |
| — | ИИ-ассистент в диалоге |
| — | экспорт сводок, тихие часы, свои фильтры по улицам |

Оплата — **Telegram Stars**: встроена в клиент, работает из России, не требует
эквайринга и юрлица. Комиссия платформы есть, но порог входа нулевой.

Ориентир по цене: 150–250 ₽/мес. Выше этой планки бесплатные городские
каналы выглядят достаточной заменой.

## 3. Реклама и локальные партнёры

Контекстная выдача в момент проблемы — самое ценное, что может дать такой бот,
и одновременно самое опасное для доверия.

Что работает: авария с водой → предложение проверенного сантехника; отключение
света → аренда генератора; протечка → служба устранения. Что не работает:
баннеры в тревожных оповещениях.

Правило, которое я бы заложил: партнёрский блок появляется **отдельным
сообщением после** решения проблемы, а не внутри оповещения о ней. И только
для бытовых категорий, никогда — для военных.

Потенциальные партнёры: управляющие компании, аварийные службы, страховые,
магазины автономного питания.

## 4. B2B — там, где реальные деньги

Частные пользователи платят неохотно, организации — регулярно.

- **Управляющие компании и ТСЖ.** Свой экземпляр бота под дома компании:
  жильцы подписываются, УК рассылает официальные уведомления через ту же
  систему. 3–10 тыс. ₽/мес за дом или пакет домов.
- **Застройщики.** Сервис для новых ЖК как часть «умного двора».
- **Бизнес с распределёнными точками** — сети магазинов, аптек, пунктов
  выдачи: мониторинг аварий сразу по всем адресам. Это ровно то, что бот
  уже умеет, — кластеризация локаций писалась под такое.
- **API-доступ** к разобранному потоку событий: город, категория, улицы, дома
  в JSON. Покупатели — агрегаторы, СМИ, аналитики.

Ограничение: с деньгами приходит ответственность. Пропущенное оповещение
у частного пользователя — досадно; у платного клиента — претензия. Нужен
SLA-оговорочный текст и понимание, что классификация вероятностная.

## 5. Донаты

Кнопка «Поддержать проект» через Telegram Stars. Не бизнес-модель, но
покрывает хостинг и оплату API, а главное — показывает, готова ли аудитория
платить вообще. Дёшево в реализации, полезно как индикатор перед запуском
подписки.

## Что я бы делал по порядку

1. **Сначала аудитория.** До сотни активных пользователей монетизация
   бессмысленна: любой процент конверсии от малого числа — ноль.
2. **Партнёрская кнопка + промокод HydraVPN.** Уже почти готово, конверсию
   видно сразу, риска нет.
3. **Донаты через Stars.** Проверка гипотезы «готовы ли платить».
4. **Freemium**, если донаты показали спрос.
5. **B2B**, когда система отработает сезон без сбоев и появится статистика
   доставленных оповещений — она же станет главным аргументом в переговорах.

## Чего делать не стоит

- Платить за оповещения об опасности. Никогда.
- Реклама внутри тревожных сообщений.
- Продажа данных о локациях пользователей — это и незаконно, и убивает проект.
- Обещания гарантированной доставки: источники публичные, ИИ вероятностный,
  Telegram может задержать сообщение. Формулировка «информационный сервис,
  не заменяет официальные каналы оповещения» должна остаться везде.
