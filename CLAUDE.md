# Радар — правила проекта

Telegram-бот мониторинга городских угроз и аварий ЖКХ по адресам пользователя.
Работает на ARM-одноплатнике за домашним роутером. Автор: SecretHero.

## Общение

- Отвечать по-русски.
- Ценится техническая честность: прямая оценка выполнимости важнее
  оптимистичных обещаний.

## Обязательные проверки перед коммитом

```bash
python3 -m unittest discover -s tests   # офлайн-тесты, без сети
python3 tools/stubcheck.py              # импорт модулей + рантайм-проверки
python3 tools/lint_names.py             # сверка имён между модулями
python3 tools/lint_undefined.py         # неопределённые имена
python3 tools/lint_pyversion.py         # совместимость с Python из образа
python3 tools/lint_docker.py            # Dockerfile против .dockerignore
python3 tools/stamp_headers.py --check  # подпись автора
python3 tools/build_installer.py        # пересборка install.sh
```

Каждая проверка появилась после реальной поломки на сервере. Пропуск любой
из них уже приводил к тому, что бот падал у пользователя.

## Устройство

- `install.sh` **генерируется** из `tools/install.template.sh` и файлов
  манифеста. Вручную не править — CI сверяет соответствие.
- Версия правится в `radar/__init__.py`, оттуда её берут установщик и бот.
- Образ собран на **Python 3.11**. Синтаксис 3.12 не использовать:
  обратный слэш и одинаковые кавычки внутри f-строк запрещены.
- Схема базы дополняется автоматически: новое поле в модели дописывается
  через `ALTER TABLE` при старте.
- Секреты — только в `.env` (права 600, в `.gitignore`). В журналы не пишутся.

## Что не обсуждается

1. Оповещения об угрозах бесплатны всегда. Платные — только новостные подборки.
2. Реклама не появляется внутри тревожных сообщений.
3. Без подтверждённой географии тревога не отправляется.
4. Событие в прошлом — сводка, а не тревога.
5. Терминала сервера в веб-панели нет и не будет.
6. Формулировка «не заменяет официальные каналы оповещения» остаётся везде.
